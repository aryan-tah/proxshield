# Code of Conduct

proxshield adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, critique code rather than people, and help newcomers. Harassment, insults and personal attacks aren't tolerated in any project space, including issues, pull requests, discussions and anywhere you represent the project.

## Reporting

Report unacceptable behaviour to the maintainer at aryan@vennbee.com. Reports are handled confidentially. The maintainer will review every report and respond as the Contributor Covenant's enforcement guidelines describe, from a private warning up to a permanent ban.
